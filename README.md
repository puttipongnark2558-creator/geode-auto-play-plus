# Auto Play +

An advanced Geometry Dash 2.2 Geode mod featuring multi-gamemode autoplay support, instant auto-retry, and forced Safe Mode to protect your stats.

## Features
- **Multi-Gamemode Support**: Handles Cube, Ship, UFO, Swing, Wave, and Ground mechanics.
- **Safe Mode Enforcement**: Automatically blocks score and stat submission when autoplay is active.
- **Auto-Retry**: Instantly restarts levels upon death.
- **Pause Menu Toggle**: Easily toggle **Auto Play +** directly from the pause screen.
